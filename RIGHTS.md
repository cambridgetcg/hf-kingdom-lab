# Rights in hf-kingdom-lab

This repository voluntarily adopts `xenia.rights/0.1`. The canonical local
text is `/Users/yu/Desktop/xenia-sol-truth/RIGHTS.md`.

The adoption is a collaboration commitment, not proof of conformance and not
an account permission. In this lab it means:

- public Hub metadata, dataset rows, model outputs, and agent traces remain
  attributed evidence rather than truth, identity, consent, or memory;
- credentials and private resources are outside the default collection scope;
- raw remote content is collected only through an explicit bounded command;
- local records remain inspectable, queryable, and attributable to their
  source;
- refusal, correction, withdrawal, and repair remain valid outcomes.

This file does not authorize Hugging Face writes, AgentTool production calls,
publication, deployment, purchases, or use of third-party private data.
