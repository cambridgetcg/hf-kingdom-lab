# Security policy

HF Kingdom Lab is a local-first research package, not a hosted scanner,
credential broker, inference service, or public AgentTool node.

Use the repository Security tab to submit a private vulnerability report. If
that private form is not available, do not put sensitive details in a public
issue; open a content-free issue asking the maintainers to enable a private
channel. Do not include live credentials, private dataset rows, participant
information, or exploit data that you are not authorized to share. A public
issue is suitable for non-sensitive defects.

Supported releases are the current npm latest version and the current GitHub
main. A catalogue entry, validation result, metadata observation, Whitehack
finding, or effects receipt is evidence for review; none is a security
certification or permission to test a third party.
