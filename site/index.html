02 / Honest machinery

Capability is not permission

Every route is narrower than the source it describes. Ambiguity stays visible; a convenient API or Viewer does not become authority.

✓ The lab does

  • pin public repository identities and revisions
  • preserve joins, drift, missingness, and disagreement
  • separate human, model, and mixed observations
  • record bounded local evidence receipts
  • fail closed when a shape changes unexpectedly

× The lab does not

  • mirror dataset rows, weights, audio, or response text
  • infer identity, demographic taste, culture, or person-worth
  • turn licences or publisher metadata into legal authority
  • erase contradictions by silently choosing one count
  • republish remote dataset bodies, mutate the Hub, or start a service
